# Code of Conduct

The mantpy project is part of the [scverse](https://scverse.org) ecosystem and
adopts the **Contributor Covenant**, version 2.1, as its Code of Conduct.

The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

All participants in mantpy project spaces — contributors, maintainers and users —
are expected to follow it, and to uphold the wider
[scverse community standards](https://scverse.org/about/).

## Reporting

To report an issue or a possible violation, contact the maintainer at
**moeghaf@gmail.com**. Reports will be reviewed and handled confidentially.
